# OrderDesk 安全说明

知华科技（上海如静知华信息科技有限公司）· https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。未经书面授权不得商用。

会话Cookie HttpOnly、SameSite Strict、30分钟，正式HTTPS设COOKIE_SECURE=true。BCrypt12轮，12–72字节密码规则；首次随机口令不入Git，重置口令撤销旧会话。CSRF默认保护写接口，匿名只能读取健康、CSRF及执行有CSRF的登录。登录失败按IP+账号限制，窗口5分钟、8次，单实例内存；部署方配置外围限流和可信代理。

每次请求重新读取启用账号与实时角色。客户仅portal+CUSTOMER、固定客户绑定与同部门，不接受客户端指定任意客户或员工权限。员工数据按ALL/DEPARTMENT；共享商品写入要求ALL。服务器接口先授权后读写；主键猜测不能读其他客户详情、常购清单、价表或导出。账号散列JSON忽略，不在日志中输出完整输入或秘密。

导入是本机浏览器UTF-8 CSV→预览→有限JSON价表事务，无文件存储或通用附件接口；浏览器CSV上限500行、512KiB；同源Nginx请求上限4MiB，服务端再次验证最多500行、缺失/重复/未知键、整数数量、价格和版本。CSV导出中和=、+、-、@等公式前缀；接收方也应安全处理表格，不执行未经审查的公式。

源码扫描覆盖已知Token/私钥格式、示例口令及二维码摘要；不代表渗透测试、审计认证或所有秘密都能被正则发现。发布前人工检查差异，测试客户使用TEST标记。安全漏洞通过官方微信私下提供脱敏复现，不在Issues发布业务数据、Cookie、真实密钥或完整数据库。
